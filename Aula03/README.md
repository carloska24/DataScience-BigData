# Aula 03 — análise de consumo energético

- `Aula03_Todos_os_Exemplos_Completo.ipynb`: exemplos completos.
- `consumo_energetico_alunos.csv`: base original usada pelo notebook completo.
- `Entrega Colab Aula03/`: notebook resolvido de entrega. Ele contém a base incorporada e não depende de uma segunda cópia do CSV nessa pasta.
- `Docs/`: instruções e guia de ambiente.
- `assets/`: imagens de apoio.

Execute o notebook completo com `Aula03` como diretório de trabalho, mantendo o CSV ao lado dele. O PDF original está em [PDFS AULAS](../PDFS%20AULAS/), e o exemplo do professor em [Codigos do Professor](../Codigos%20do%20Professor/).

Para executar o guia que está em `Docs/`, use também `Aula03` como diretório de trabalho; a célula de leitura procura o CSV na pasta atual.
